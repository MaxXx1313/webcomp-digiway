# Custom Icon Font: noi-digiway-weather-icons

This folder contains the master source SVG files used to generate our custom icon font, **noi-digiway-map-icons**.

Using an icon font ensures that all map icons render sharply, scale infinitely without losing quality, and load efficiently via a single network request.

## Core Naming Rules

- **Time of Day**: Use `sun` and `moon` as the first part so you know if the sun or moon is out.
- **Main Weather**: Use simple words for the main look, like `clear`, `clouds`, `rain`, `snow`, or `thunder`.
- **Modifiers**: Add extra details at the end, like `light`, `heavy`, `scattered`, or `windy`.
